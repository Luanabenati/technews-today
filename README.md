# 🚀 TechNews Today — Portal de Tecnologia
Um portal de notícias sobre tecnologia com visual moderno, efeitos de vidro, gradientes e layout responsivo, desenvolvido com HTML e CSS.

## 🎯 Objetivo

Modernizar a interface de um portal de notícias utilizando recursos de estilização e layout, mantendo a estrutura HTML original e sem utilizar frameworks ou JavaScript.




## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- CSS Grid
- Media Queries
- Glassmorphism
- Gradientes e transições
